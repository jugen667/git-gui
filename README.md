# Git GUI 
Simple GUI for providing Git command 

## Simple GUI that provides commands for your Git actions

Open your repo by giving it your path, get the status and add your wanted file. Write your comment, add the option you need, click generate and voila ! Copy paste the command in your terminal.

## Build info

- To build the software : ```qmake && make all && bin/git-gui```
